# Eon 2 — ilk ön sürüm doğrulaması

Tarih: 13 Kasım 2026 (Europe/Istanbul). Sürüm: **2.0.0-preview.1**.

Bu yayın kullanıcının GitHub tanıtımı ve ilk Eon 2 release isteğiyle hazırlanmıştır. v1.1.0 ve v1.2.0 yayınları korunur. Eon 2 için kararlı üretim kabulü iddia edilmez.

## Kapsam

- Güncel ürün kapsamını anlatan README, altı masaüstü ekran görüntüsü ve `docs/USAGE.tr.md` rehberi.
- Windows NSIS ön sürüm paketi, ayrı Android geliştirme APK'sı ve SHA-256 kontrol dosyası.
- `package.json` / kilit dosyasında ön sürüm kimliği.
- Güncel Eon 2 test komutu ve Windows CI kontrolleri; Android/scrcpy hazırlığı eklenmiş, sonraki otomatik yayınları inceleme için taslak oluşturan release iş akışı.
- `tsx` artık sabitlenmiş geliştirme bağımlılığıdır: mevcut testler önceden npx önbelleğine/ağdan geçici çözümlemeye bağımlıydı. Yeni üretim bağımlılığı eklenmedi.

Paketlenmiş `app.asar` içindeki sürüm `2.0.0-preview.1` olarak okundu. Windows kurulum dosyasının Authenticode durumu `NotSigned` olarak doğrulandı. SHA256SUMS.txt yalnızca bu yayının installer, blockmap, Android APK ve latest.yml dosyalarını kapsar. Bu oturumda kurulum paketi yeniden bu bilgisayara yüklenmedi; 12 Kasım kurulum kanıtı yeni paketin kabulü sayılmaz.

Android'in ilk yerel test denemesi Türkçe karakter içeren çalışma yolunda `ClassNotFoundException` ile başarısız oldu. Ardından Android kaynağı build/cache dizinleri olmadan `%TEMP%/EonRelease-20261113-Android` altına kopyalandı ve derleme/test/lint baştan başarılı çalıştı. JDK: Android Studio JBR 21.0.5. SDK: 37. İlk başarısızlık başarılı test olarak sayılmadı; ana çalışma ağacının verileri silinmedi.

Görseller, güncel derlenmiş Electron/React arayüzünden ayrı, geçici bir kullanıcı profiliyle alınmıştır. Kişisel notlar ve API anahtarı kullanılmadı; cihaz listesi gizlendi ve bilgisayar adı görsel alınmadan önce genel bir etiketle değiştirildi. Bunlar Android fiziksel cihaz kabul kanıtı değildir. Altı görsel görsel olarak incelendi.

Yerel kanıtlar (depoya eklenmez): `builds/publish/`, `docs/eon2/qa-deck-mirror/`; Android test XML ve lint raporları temiz kopyanın `app/build/` dizinindedir.

## Açık sınırlar

- Windows kurulum dosyası Authenticode imzalı değildir; Android APK'sı geliştirme anahtarıyla imzalı `com.kapanis.mobil.eon2.dev` paketidir.
- Fiziksel USB çıkar/tak, Windows yeniden başlatma, tailnet kesintisi, iki fiziksel cihaz arasında dosya/not kabulü ve PC ekranının tüm donanım durumları bu oturumda yeniden test edilmedi.
- TalkBack/ekran okuyucu matrisi ve ölçülmüş p95 performans kabulü tamamlanmadı.
- Notların v1 Vault'tan otomatik geçişi yoktur; geri dönüşten önce v1 ve Eon 2 verilerini ayrı yedekleyin. Ayar dışa aktarımı not yedeği değildir.
- Vite, 500 kB üzerindeki mevcut not editörü paketine ilişkin uyarı bildirdi.
- npm kurulum denetimi 14 bağımlılık bulgusu (6 orta, 8 yüksek) bildirdi. Bu oturumda kapsamlı güvenlik incelemesi veya kırıcı bağımlılık güncellemesi yapılmadı; güvenlik onayı iddia edilmez.
- GitHub Actions iş akışlarının uzak çalışması yerel testlerden ayrıdır. İş akışındaki scrcpy 3.2 arşiv özeti resmi `Genymobile/scrcpy` SHA256SUMS.txt ile karşılaştırılmıştır.

## Yedek ve geri dönüş

Önemli verileri ön sürümden önce yedekleyin. Eon kapalıyken kullanıcı veri dizinindeki `eon-2` deposunun tam kopyasını alın; eski Vault'u koruyun. Önceki sürüm paketleri GitHub Releases'te kalır. v1'e dönmek, Eon 2 not deposunu v1 biçimine dönüştürmez. Ön sürüm otomatik güncellemesi/geri dönüşü bu oturumda kabul edilmedi.
