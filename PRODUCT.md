# Eon

<!-- impeccable:product-schema 1 -->

## Platform

android

## Product Purpose

Eon connects the Android companion and Windows workspace for computer controls,
Deck widgets, local Markdown notes and transfers. The user confirmed a balanced
mobile experience led by Panel and Deck on 2026-11-12.

## Capabilities and Constraints

Preserve existing notes, pairing, permissions, control actions, layouts and themes.
Android uses Kotlin and Jetpack Compose; Windows uses React and Electron.
Deck layout, spacing, editing and widget behavior stay consistent on both platforms.
Keep the development package separate from the legacy installation.

## Brand Commitments

Preserve Eon and its planet logo. The requested redesign is premium liquid glass
across shared components, navigation, screens and Deck, retaining all five themes.
Smooth scrolling, fast feedback and bounded resource lifetimes are priorities.

Release state and physical-device evidence: `docs/eon2`.
Performance and absence of memory leaks require measurements, not visual inference.
